### Підтримка та супровід

## Стандарти
- Node LTS 20/22, Vite 6, React 18, TypeScript strict.
- ESLint + @typescript-eslint + React Hooks rules; Prettier (за потреби) — однакове форматування.
- Коміти за Conventional Commits; PR — з чек-листом і посиланням на таску.

## CI/CD (рекомендація)
- Перевірки: `type-check`, `lint`, `build`, smoke e2e (Playwright) по ключових фічах.
- Перевірка `.env` змінних (presence) та статичних конфігів.

## Релізи
- Семвер мінор/патч для UI; зміни контрактів API — синхронізовані теги з бекендом.

## Моніторинг
- Логи помилок у браузері (Sentry/LogRocket) — ключові точки: підпис транзакцій, відправка, мережеві помилки API.

## Оновлення залежностей
- Раз на спринт: audit та оновлення minor/patch. Major — через окремі епік-таски з регресією.
